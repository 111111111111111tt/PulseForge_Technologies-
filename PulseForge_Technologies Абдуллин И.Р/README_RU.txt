PULSEFORGE TECHNOLOGIES — учебный проект Flask + SQLite

ЗАПУСК В WINDOWS
1. Распакуйте архив в удобную папку, например C:\Users\User\Downloads\PulseForge_Technologies
2. Откройте эту папку в Проводнике. Убедитесь, что внутри виден app.py.
3. Нажмите адресную строку Проводника, введите cmd и нажмите Enter.
4. Выполните команды по очереди:

   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   python app.py

5. Откройте http://127.0.0.1:5000

ПРОВЕРКА БАЗЫ ДАННЫХ
1. Откройте раздел «Контакты».
2. Отправьте тестовое сообщение с вымышленными данными.
3. Перейдите на http://127.0.0.1:5000/admin
4. Сообщение должно появиться в списке.
Файл organization.db создаётся автоматически рядом с app.py. В нём таблицы services и messages.

ВАЖНО
- Не запускайте команды из C:\Windows\System32. Командная строка должна быть открыта в папке, где лежит app.py.
- Пока работает сайт, не закрывайте окно CMD с запущенным python app.py.
- /admin не имеет авторизации и предназначен только для локальной учебной демонстрации.
- Не публикуйте проект в интернете в текущем виде. Для реального размещения нужно добавить авторизацию, убрать debug-режим и настроить секретный ключ.
- Контакты на сайте демонстрационные, адрес hello@pulseforge.example не является реальной почтой.
