ТЕКСТ ДЛЯ ЗАЩИТЫ — PULSEFORGE TECHNOLOGIES

Здравствуйте! Я подготовил(а) учебный сайт IT-компании PulseForge Technologies.

Цель проекта — создать веб-сайт компании, которая предлагает цифровые решения для бизнеса, а также реализовать форму обратной связи с сохранением данных в базе данных.

Для разработки использованы Python, Flask, HTML, CSS и SQLite. Python отвечает за серверную логику, Flask обрабатывает запросы, HTML задаёт структуру страниц, CSS отвечает за оформление, а SQLite хранит данные.

Сайт включает главную страницу, страницу «О компании» и страницу контактов. На главной странице представлен каталог услуг: веб-разработка, автоматизация процессов и работа с базами данных. Список услуг загружается из базы данных SQLite.

В базе данных созданы две таблицы. Таблица services содержит название услуги, описание и цену. Таблица messages содержит имя отправителя, электронную почту, текст обращения и дату создания.

Для демонстрации я открываю раздел «Контакты», заполняю форму тестовыми данными и отправляю сообщение. Сервер Flask принимает данные и сохраняет их в SQLite с помощью параметризованного SQL-запроса. Затем я открываю учебную страницу /admin и показываю сохранённое обращение.

Таким образом, проект демонстрирует не только оформление сайта, но и взаимодействие веб-приложения с базой данных. В дальнейшем можно добавить авторизацию администратора, возможность редактирования услуг и публикацию сайта на сервере после настройки безопасности.
